# CareerConnect — User Stories

## AI-Generated User Stories

The 10 stories below were generated by prompting an AI assistant (Claude,
via Claude Code) as required for Sprint 1. They are logged verbatim in
`AI_Log/Mahmoud_Abdalla/sprint1-ai-usage-log.md` (entry: "Generate 10 User
Stories"). They have been lightly reviewed against the project brief's
feature list but **not yet validated in a team meeting** — treat them as a
starting draft, not final backlog items.

| ID | Story | Suggested Tasks |
|----|-------|------------------|
| US-01 | As a job seeker, I want to create an account so that I can access platform features. | 1.1 Design User schema · 1.2 Build `/api/register` endpoint · 1.3 Build registration form UI |
| US-02 | As a job seeker, I want to log in securely so that my application data stays private. | 2.1 Configure NextAuth credentials provider · 2.2 Hash/verify passwords · 2.3 Build login form UI |
| US-03 | As a job seeker, I want to upload and manage my resume so that recruiters can review my qualifications. | 3.1 Build resume upload API · 3.2 Validate file type/size · 3.3 Display current resume on profile |
| US-04 | As a job seeker, I want to edit my profile (headline, bio) so that I can present myself professionally. | 4.1 Build profile GET/PATCH API · 4.2 Build profile edit form |
| US-05 | As a recruiter, I want to post a new job opening so that job seekers can apply. | 5.1 Design JobPosting schema · 5.2 Build job creation API · 5.3 Build job posting form UI |
| US-06 | As a recruiter, I want to edit or close a job posting so that my listings stay accurate. | 6.1 Build job edit/close API · 6.2 Build recruiter dashboard list view |
| US-07 | As a job seeker, I want to search and filter job postings (by title, location, type) so that I can find relevant opportunities quickly. | 7.1 Build job search API with filters · 7.2 Build search/filter UI |
| US-08 | As a job seeker, I want to submit an application to a job posting so that I can be considered for the role. | 8.1 Design Application schema · 8.2 Build apply endpoint · 8.3 Build "Apply" button/flow |
| US-09 | As a job seeker, I want to track the status of each application (Applied, Interview, Offered, Rejected) so that I know where I stand. | 9.1 Add status field + transitions · 9.2 Build application history dashboard |
| US-10 | As a job seeker, I want to save jobs to a favorites list so that I can revisit and apply to them later. | 10.1 Design SavedJob schema · 10.2 Build save/unsave endpoint · 10.3 Build saved-jobs list UI |
